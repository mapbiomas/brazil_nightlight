# Collection 1 | Version 1.0

Initial public code release for MapBiomas Brazil Nighttime Radiance, covering 2013–2025. The workflow implements annual direct VIIRS radiance estimation with quality screening, robust log-space filtering, quality weighting and lognormal back-transformation. Each annual output includes radiance and observation-support information in an 18-band schema. The 250 m distribution grid does not imply improved native VIIRS spatial resolution.

See the [official ATBD](https://brasil.mapbiomas.org/wp-content/uploads/sites/3/2026/09/ATBD-General-Collection-11-versao-ALAN_verFINAL.pdf) for the methodological specification and empirical validation.
